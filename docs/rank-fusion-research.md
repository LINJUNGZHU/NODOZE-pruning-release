# 排序分支研究：RASP-RRF（2026-09-10）

## 论文和公开项目实际提供的启发

1. [GDC，NeurIPS 2019](https://proceedings.neurips.cc/paper/2019/hash/23c894276a2c5a16470e6a31f4618d73-Abstract.html) 与[官方实现](https://github.com/gasteigerjo/gdc)：将扩散与后续学习解耦，比较 PPR/heat 等传播核。检查了 `gdc_demo.ipynb` 的扩散、阈值稀疏化、再归一化流程。其阈值作用于扩散图，不是在严格保护原始攻击事件的条件下剪枝；不能直接等价迁移。演示中的矩阵求逆也不适合作为我们的持续日志处理路径。本轮没有实现 GDC 模型。
2. [APPNP，ICLR 2019](https://arxiv.org/abs/1810.05997) 与[官方项目](https://github.com/gasteigerjo/ppnp)：区分预测和传播，提醒我们应分别评估“局部异常证据”“传播”“最终排序”，不能只汇报组合结果。本轮没有训练 APPNP，也不将当前 RASP 叫作 APPNP。
3. [ATLAS，USENIX Security 2021](https://www.usenix.org/system/files/sec21-alsaheel.pdf) 与[官方项目](https://github.com/purseclab/ATLAS)：学习事件序列的调查语义，是未来补足常见操作组成攻击的方向。公开项目包含训练依赖与其日志数据；尚未直接运行，更没有把这些数据当成我们的独立 CADETS 测试。缺少合适训练划分时，本轮不引入监督序列模型。
4. [RRF，SIGIR 2009](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf)：这轮实际实现的算法基础。不同排序器按 `sum(1/(60+rank))` 融合，不需要混合不可比的原始分数。固定 k=60 来自原文，不代表已证明适合安全日志。

## 实现与适配

`tc_pruning/rank_fusion.py` 实现排名融合，并增加并列平均名次、零证据不投票和不可达事件排除。这样相同分数不因 UUID 排序而产生不公平的额外投票。
两路输入是原 RASP 和带稀有度的未校正 PPR；三路消融额外加入独立稀有度排名。注意两路原本就包含稀有度，三路并不是三个独立证据源。
RRF 输出是选边优先级，不是异常概率；每条边仍保存原分数、PPR、稀有度、两种融合分数和全部预算决策。
时序分叉连接选择器不变，连接与 POI 都计入硬预算。

复杂度主要是每路 O(E log E) 排序；不是已完成的逐边增量排名算法。当前运行在冻结候选图上，尚未接入动态 PPR 流水线或替换网页默认方法。

## 四案例 64 组实验

配置 `configs/rasp_rank_fusion.json` 在运行前固定：4 种排序 × 4000 边/5%/10%/20% 上限，四案例相同；主分支预设为双路 RRF。所有选择掩码冻结后读取攻击真值。结果属于开发集，不是泛化验证。

这轮没有按案例选择最优方法，也不能取每行最大值作为某个统一算法的结果。

## 定位到的问题

- 背景校正不是普遍有益：CADETS-12 10% 纯 PPR 99.02%，原 RASP 15.44%；但 THEIA 同预算纯 PPR 30.92%，原 RASP 98.85%。需要研究在独立验证数据上可靠选择或校准证据，不能手工按场景切换。
- 融合不保证胜过最佳单路：CADETS-12 的部分收益来自加入更强的纯 PPR 分支，不能全部算作 RRF 的贡献。
- CADETS-12 标注事件的稀有度中位数只有约 0.01634，攻击行为大量使用常见操作。独立稀有度排名可能重复惩罚它们，三路融合的退步与这一机制相符，但不是完整因果证明。
- 这些结果与上一轮“历史回查”的指标不是直接对照：本轮使用完整固定候选图，上一轮使用热窗口加检索候选。
- 所有64组都未超预算、没有丢失所选事件的既有 POI 分叉连接。该审计不是攻击完整性保证。

因此保留 RRF 为可复现实验分支，不部署为默认。继续完善需要独立的正常训练日志和未参与调参的攻击验证；尤其应比较序列异常与传播证据，而不是在这四个案例上不断选最优权重。

## 复现

```bash
cd /root/NODOZE-pruning-release
run_id=$(date '+%Y-%m-%d_%H-%M-%S')
setsid -f python -u -m scripts.run_rank_fusion \
  --ledger output/tc/poi-prefix-sweep/2026-09-09_10-47-48/scenario-12/poi-prefix-8-ledger/edge-scores.jsonl.gz \
  --reference output/tc/poi-prefix-sweep/2026-09-09_10-47-48/scenario-12/fixed-reference.json \
  --output "output/tc/rank-fusion-CADETS-12-${run_id}" \
  > "logs/rank-fusion-CADETS-12-${run_id}.log" 2>&1 < /dev/null
```

本轮四案例日志时间戳 `2026-09-10_18-42-14`，全部 COMPLETE。
`comparison.json` 保存配置、代码与选边输入哈希、全部指标；`edge-ranks.jsonl.gz` 保存逐边证据与决策。原始数据、运行产物不上传 GitHub。
