# 按参考保留目标调整压缩率

现有工作台支持先设定保留目标，再选择已测预算中压缩率最高的达标点。默认同时要求**原生参考事件保留率与可行事件依赖保留率至少95%**；可切换90%、99%、100%，并追加固定入口—出口可达率约束。曲线可切换事件保留、依赖保留、端点可达和完整子图四种指标。

这是使用离线参考评价筛选预算的事后分析。选择预算时使用了参考指标，因此只能说明这个已观测实验点满足目标，不能作为未知日志上的正确率保证，也不能当作新的无标签自适应算法成绩。标注缺少完整负例范围，无法将保留率解释成分类准确率或精确率。部分保留允许缺失成员，不等于完整攻击。

## 95%目标下的实际结果

下表固定当前方法 `reliability_chain` 与 `declared` POI。除明确标注的扩展范围外均为基础候选；指标分母使用原生参考，事件指标包含单例。每一行都是**同一个实际选择点**同时满足事件和依赖目标，未跨方法、跨预算拼接最高指标。

| 案例与候选范围 | 达标预算 | 实际压缩率 | 参考事件保留 | 事件依赖保留 | 入口—出口可达 |
|---|---:|---:|---:|---:|---:|
| CADETS06 基础 | 1022 | 99.00% | 165/166（99.40%） | 5746/5829（98.58%） | 8/9（88.89%） |
| CADETS06 扩展 | 1024 | 99.31% | 165/166（99.40%） | 5746/5829（98.58%） | 8/9（88.89%） |
| CADETS13 扩展 | 14864 | 80.00% | 118/118（100%） | 3384/3384（100%） | 7/7（100%） |
| FIVEDIRECTIONS case1 基础 | 233128 | 50.00% | 37/37（100%） | 121/121（100%） | 79/79（100%） |
| THEIA case1 基础 | 449126 | 50.00% | 239/239（100%） | 463/463（100%） | 449/449（100%） |
| THEIA case3 基础 | 256 | 99.98% | 222/229（96.94%） | 218/228（95.61%） | 218/220（99.09%） |

如果同时要求端点可达率至少95%，CADETS06基础范围改为预算2044、压缩98.00%，扩展范围改为预算1475、压缩99.00%，两者三项指标均为100%；其余表中案例所选预算不变。不同候选范围改变压缩率分母，不能把扩大候选后的比例提高直接当作方法收益，页面同时提供固定源范围压缩率。

THEIA case3的默认目标预算从先前展示的1024降到256，实际保留事件数减少75%；参考事件保留率从97.82%降到96.94%，依赖保留率从96.05%降到95.61%，仍同时超过95%。如果目标提高到99%，该案例在已测预算113221达到三项100%，压缩率约90.00%。保留目标决定可接受的压缩水平。

以下情况无法仅靠当前已测预算满足95%的共同目标：

| 案例 | 观测到的限制 |
|---|---|
| CADETS12 基础／扩展 | 最好的共同保留水平为事件95.45%、依赖92.50%；没有同时达到95%的预算点。即使预算上限等于候选总量，也未改善这两项。 |
| CADETS13 基础 | 候选中仅覆盖79/118个参考事件（66.95%）；预算无法取回候选外事件，需要扩窗。 |
| FIVEDIRECTIONS case3 | 当前方法时序资格只覆盖13/14个参考事件（92.86%），无法用预算跨过这一事件覆盖上限。 |
| THEIA case5 | 无适用参考标注，目标状态为N/A。 |
| TRACE原生范围 | 只有单事件参考，依赖保留率无分母，共同目标为N/A。可单独查看事件指标，但不能声称依赖目标已达标。 |

这些结果使用既有10个预算采样点。所选压缩率是已测网格中的最高值，不能推断未测预算是否满足目标。预算增长也不被假定为保留率严格单调：程序逐点检查实际结果。无达标点时，展示使所需指标的最小值最高的一个已测点作为诊断；相同指标水平优先实际压缩率更高、预算更小的点。

## 数据与复现

本分析沿用9个E3案例、36个变体、7种方法及2520个冻结决策。原生／含合成关系两个参考范围、4档目标、是否约束端点两种条件共得到**4032个预算筛选记录**；它们不构成4032次新的算法实验。
