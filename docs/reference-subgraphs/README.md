# 从路径保留到参考子图完整性

本扩展沿用 `20260930-r1` 已冻结的选择，新增子图评价与本机展示。它把相互重叠的时序路径归并为固定的参考依赖子图，保留分叉、汇合和全部必需事件；不把子图数量称为独立攻击次数。

这是已有开发实验的事后结构分析。子图口径在上一轮结果产生后新增，不能将其描述为运行前预注册的独立测试，也不提供算法泛化或显著性的证据。

## 本次实测结果

已核验9个E3案例、36个变体和2520个冻结决策；原生与增强两个参考范围产生5040行指标，仍是同一批2520个决策。发布33张图表文件，并为15个既有本机保留图增加逐成员子图审查叠层。

CADETS06只丢了一个必需事件，路径保留已达120/121，严格子图仍为0/1；THEIA case3保留218/221条路径和218/220个端点对，完整子图只有1/2。它们说明路径比例或端点可达性不足以证明全部结构保留。

子图比例本身也不能单独作为结论：THEIA case1保住两个较小分量，得到2/3完整子图，但只保留14/239个参考事件。FIVEDIRECTIONS case3的多事件子图完整，却仍丢掉2个单事件参考。因此页面同时显示组件数量、全部参考事件覆盖、单例和可达性；组件数量较少时，完整率曲线天然呈阶梯，不能从连线推断未测预算的结果。

阶段诊断保留了不同问题的归属。CADETS13在基础候选中已缺失39/118个参考事件，子图首次损失属于候选阶段；CADETS12的4个子图中，1个首先损失于时序资格阶段，另3个损失于最终选择。扩窗解决候选覆盖后，也仍须检查实际选择能否保住全部结构。

当前融合方法仍有明确负例：CADETS13的 `expanded / adaptive` 中，`diffusion_only` 在已测预算743已保住1/1个子图、118/118个事件和7/7个端点对，压缩率99.0003%；`reliability_chain` 到已测预算37161才首次达到这三项完整，压缩率50.0007%。预算14864时后者已有73/75条完整旧路径，却仍缺2个必需事件，子图为0/1。在更低的预算256，两者子图均不完整，融合方法的事件覆盖44/118则高于扩散的1/118。这是本次预算网格上的比较，不是精确最小预算；不能据此宣称融合方法全面优于扩散基线。新评价没有重新调参、重选图或自动替换默认方法。

THEIA case5无适用参考，TRACE原生范围只有29个单事件；二者的原生多事件子图完整率均为N/A。TRACE增强范围则有1个多事件分量和27个单例，使用另一个分母。E5目前仍仅找到标注，未补造事件实验。

## 图与分母

每条源数据库可解析的参考正例事件是一个顶点。事件之间只有满足以下条件才建立“可行时序转移”：前一事件的因果目标等于后一事件的因果来源，二者精确时间都为正且严格递增，明确的主机身份不冲突。EXECUTE沿用文件到进程的因果方向。未知时间事件作为必需单例保留；未知主机产生的推断转移单独计数。

在这个事件DAG上取互不重叠的弱连通分量，形成固定评价单元。含至少两个事件的分量是参考子图；单事件另列。分量在剪枝前固定，删掉一条分支后不能重新拆成几个小分量再声称全部完整。相同实体的静态连通性不足以证明存在合法的时间路径。

原生范围 `native` 排除标为LINEAGE的合成事件；增强范围 `augmented` 包含它们。两种范围独立派生分量，分母可能不同。源库无法解析的参考事件另记覆盖缺口，不会凭空获得一个可验证组件。未标注场景与零分母均为N/A。

## 指标

| 指标 | 含义 |
|---|---|
| 完整参考子图保留率 | 完整保留的多事件分量数 / 固定多事件分量数；全部必需事件都必须保留 |
| 参考事件覆盖率 | 保留的不同参考事件 / 当前参考范围的全部事件，包含单例 |
| 固定入口—出口可达率 | 剪枝后仍可达的固定拓扑端点对 / 源图本来可达的端点对；不把新断点当新入口 |
| 可行时序转移保留率 | 两端事件仍保留的源图转移数 / 全部源图转移数 |
| 分叉／汇合邻域完整率 | 源图传递约简中分叉或汇合事件及其固定直接邻居全部保留的比例 |
| 阶段首失 | 一个参考子图首次在source、candidate、temporal_eligible、retained哪个阶段失去必需事件 |

可达率与严格完整性分别报告。两条替代分支中删掉一条，入口到出口仍可能连通，但子图已经不完整。传递约简仅用于定义局部分叉/汇合邻域；掩码后的可达性始终在完整可行转移图上计算，因为传递约简与删除事件不交换。

拓扑入口、出口不能直接解释为入侵入口、外传出口等攻击阶段。实体相接和时间递增只说明转移可行，尚未证明真实的信息流；当前没有重建文件版本或进程状态版本。参考标签之外的中间依赖也不会被自动补成真值；固定组件的全部事件保留，仍不足以证明现实攻击范围已经完整。独立完整攻击数量、攻击阶段完整性在本实验中保持未知。

## 复现与查看

```bash
python -m scripts.evaluate_reference_subgraphs --input output/research/chain-workbench-v2/20260930-r1 --base-report output/research/chain-workbench-v2/20260930-r1/report.json --output output/research/chain-workbench-v2/20260930-r1/subgraphs/report.json --catalog webapp/frontend/retained-chain-catalog.json --local-output output/research/chain-workbench-v2/20260930-r1/subgraphs/local-audits
python -m scripts.plot_reference_subgraphs --input output/research/chain-workbench-v2/20260930-r1/subgraphs/report.json --output output/research/chain-workbench-v2/20260930-r1/subgraphs/figures
```

输出目录必须是新路径。默认先验证登记的全部冻结案例，再打开参考；`--allow-partial`仅用于明确的已完成子集，不能跳过已启动但未完成的案例。新报告绑定旧v2报告的精确字节哈希、参考文件哈希、源正例快照哈希及评价实现哈希；本机叠层还绑定具体manifest、方法和整数预算，并与实际导出事件逐条核对。

将公开报告复制到 `webapp/frontend/chain-subgraph-summary.json` 后，现有研究工作台会在同一案例、范围、起点、方法和预算下展示子图指标。实际保留图目录可为对应导出增加 `reference_subgraph_audit_url`，指向本机叠层。页面的聚合实体图只用于浏览，完整性由离线事件DAG计算，显示筛选不改变分母。

公开材料仅包含聚合JSON、CSV和图表；详细子图、成员事件、实体语义和本机截图均保留本机。
