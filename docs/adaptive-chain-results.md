- CADETS-06，102,232 条候选，保留 1,022 条（实际压缩 99.0003%）：原 RASP 完整派生参考路径 120/121，新融合 121/121；正例事件 165/166 → 166/166。
- 三个合成多分支案例，各 1,042 事件、保留 52 条（压缩 95.0096%）：原 RASP 完整链合计 0/18，新融合 13/18（72.22%）。合成结果只验证构造机制，不等同于真实攻击提升。
- CADETS-12，1% 与 5% 预算下，新融合正例事件保留为 36/44，原 RASP 为 39/44；完整派生路径同为 1/31。20% 预算时两者均 4/31、42/44。新方法没有全面占优，未替换已有默认。
- CADETS-13，候选只有 79/118 个正例事件，75 条长派生参考路径均不完整，故所有剪枝方法完整参考路径率为 0。原始 118 个事件全部能在数据库找到，39 个事件首次丢失于候选阶段。此结论不能靠更换剪枝评分解决。
- 真实场景没有独立审核且范围完整的攻击链合同；已核验完整攻击链指标全部 N/A。121/31/75 是自动派生、可重叠的参考路径数量，不是独立攻击活动数。


本机本轮冻结目录：`output/adaptive-chain-study-20260929-final/`。每场景包含候选与历史白名单输入、分数、全部预算决策、时序/组证据和摘要；`--validate` 核对输入身份、方法×预算完整矩阵、预算/告警/有效域及各产物契约。源数据库、真实事件参考文件、详细网页报告与冻结输入均只保留本机并由 `.gitignore` 排除。公开仓库包含代码、白名单聚合的 `chain-study-summary.json`、CSV 和可导出的图；聚合文件不含事件标识、实体语义或逐边评分。网页只有在详细报告返回 404 时才回退汇总，明确提示事件明细需本机生成。

重新克隆后，直接启动网页即可查看汇总主图和阶段计数。真实数据复现需按配置放好数据库、候选账本，并将已有 CAPTAIN 事件标注放入 `poi/`，再运行 `prepare_chain_references`；参见[本地参考准备](../configs/chain_references/README.md)。`--synthetic-only` 可独立运行，无需这些真实数据文件。`--publish` 只写本地页面资源，不执行 Git 上传。
