# 评分相同、判定阈值与可复核的因果选边

本次优化针对已有 RASP 调查方法的证据解释与选择逻辑，不宣称实现了新的独立入侵检测器。
下述新目标与证明适用于可选的证据子图模式；默认扩展上下文保留旧 RASP-D 行为。
小预算对照中出现负结果，因此没有用新模式替换默认策略。两种模式都提供可重放的判定轨迹。
文献与官方开源实现的研读记录见 [研究记录](provenance-selection-literature.md)。

## 1. 为什么评分会相同

优化前的默认 OPTC 窗口有 27,011 条边，原始传播分有 1,923 个不同取值；四位小数显示仅剩 91 种。
同端点、同关系、同历史稀有度的重复事件共享同一个图传播通道，因而获得相同传播分。
不同 UUID 的叶子如果结构对称、历史计数相同，也可能获得相同分数。
这是所使用特征不能区分它们，不能通过随机扰动、事件 ID 小数尾巴或者未经验证的时间衰减掩饰。

旧分数还混合了 `escape_floor=1e-6` 的传播保底通道。默认保留 5,402 条边中，4,918 条的背景对比分量为零。
这些边拥有的极小非零分数有助于维持上下文，但不应被解释成积极的异常证据。
新模式显示背景对比分量；旧传播分仍保存在 `propagation_score`，扩展上下文模式继续使用它。
页面显示九位有效数字、完整精度 tooltip 和真实同分组大小。同分仍保留。

## 2. 分数、资格与决策是三件事

令候选事件集为 E，指定 POI 为 p，历史统计条件始终为 `t(e) < t(p)`。
对每个节点 v，`P_p(v)` 是 POI 个性化 PageRank，`P_b(v)` 是以进程为背景的 PageRank。
沿用现有 RASP 的相对背景传播、历史稀有度和逐 POI 归一化，得到背景对比证据分 `c(e)`。
它是调查相关性分，不是恶意概率。

数值上使用 PPR 的收缩性：重启率为 r，迭代残差为 δ，则在标准实数运算模型下，
返回迭代点与不动点的 L1 距离至多为 `δ/r`。每个分量误差也不超过此值。
因此对边的两个端点分别要求：

```
P_p(v) - P_b(v) > δ_p/r + δ_b/r
```

这比直接比较浮点数是否大于零更稳健。代码记录两端差值中较小者减去误差界的下界。
此处是 **PPR 收敛误差界**，不是统计置信区间，也不是误报率保证。
实现使用双精度浮点，未声称经过区间算术的机器舍入误差认证。

证据锚点集合 A：`c(e)>0`、上述数值边界检查通过、存在到 POI 的严格时序见证。
手动指定的 POI 单独强制保留，不需要通过异常检验。

一个有分数的事件可能因为没有时序见证或完整路径装不进剩余预算而被删除。
一个零证据分的事件也可能是连接锚点到 POI 必须经过的边。
所以通用判定 **不能写成 `score >= threshold`**；本次实际结果也检查了是否存在等价的单边阈值。

## 3. 固定时序见证与可行性

沿用 `temporal_routes` 和 `temporal_fork_routes` 构造每个可达事件的固定路径束 W(e)：
一条严格时间递增的前向分支，以及共同起点通往 POI 的严格时间递增分支。
它们可以形成因果分叉，不冒充一条贯穿全部事件的单调路径。
POI 和分叉起点暴露两个端点的调查状态，其余连接遵循实际信息流方向。
同刻事件不互相传递状态。

可行结果是 POI 与若干完整 W(e) 的并集，且实际原始事件数量不超过预算 B。
重叠连接边仅计费一次。默认 B 是 20% 上限；证据已经保留完时停止，不填充剩余预算。
该路径束由确定性的最小跳数过程给出；它并非全体可能路径，未证明其中不存在其他更短或更好的解释。

## 4. 明确优化目标

按历史语义交互签名划分组 g，避免仅因网络连接 UUID 不同就把同一行为当作全新的证据。
令 `w_g=max_{e∈A∩g} c(e)`，`m_g(S)=Σ_{e∈S∩A∩g} c(e)`。
对于非零权重的组，定义：

```
F(S) = q Σ_g m_g(S) + (1-q) Σ_g w_g log(1 + m_g(S)/w_g)
q = 0.05
```

零权重组贡献为零。连接边计入事件预算，只有同时属于 A 的边才贡献证据收益。
这个目标使同语义组的重复证据边际收益递减，但不会捏造边分数的差别。

每一步枚举所有未保留的合法证据锚点，计算其完整路径新增部分：

```
D(e,S) = W(e) \ S
Δ(e,S) = F(S ∪ W(e)) - F(S)
优先级 = Δ(e,S) / |D(e,S)|
```

只考虑 `0 < |D(e,S)| <= B-|S|`。按收益率、总收益排序；完全同优先级时按距 POI 时间、
时间戳、事件 ID 确定顺序。这些二级规则不改变 c(e)。每步重算路径总收益与新增成本，
不使用可能因共享连接变化而失效的惰性收益/成本上界。

这是有完整连接约束的确定性贪心法。尽管 F 对事件集合具有单调、边际递减结构，
**不能把无连接约束的子模最大化近似比，或者 NODLINK 的 Steiner Tree 竞争比移植过来。**
也不宣称贪心解总是全局最优。

## 5. 能证明什么

- **预算**：归纳检查每次只加入不超过剩余预算的 D，故最终 `|S|<=B`。
- **POI 保留**：初始集合包含 POI，后续只添加事件。
- **连接完整**：每次添加整条路径束，已选边只增加，故每个拥有者锚点的见证始终完整。
- **正收益**：每次接受的 Δ>0；日志记录的 Δ 等于重算的目标函数差值。
- **有限终止**：每步至少新增一条边；至多 B 步，或者再无可行的正收益路径束。
- **目标值上界**：忽略预算和连接成本，把全部 A 都保留，得到 `U=F(A)`。
  由于目标单调，任何可行解都有 `F(S*)<=U`。实际解给出下界 L=F(S)。
  `L/U` 是相对于这个松弛上界的保证比例；下界等于上界时，只证明这个指定目标与固定证据集合下的最优值。
  不代表找全攻击，不代表攻击检测准确率，不代表在其他数据上也能达到该上界。

这些是可执行的算法契约。它们既不证明采集日志真实完整，也不证明 PDF 指标匹配就是恶意事件。

## 6. 每条边的判定证据

所有事件都有 `decision`，包括删除事件：

| 判定代码 | 含义 |
|---|---|
| manual_poi | 人工指定的调查起点 |
| evidence | 合格背景增益证据，完整见证已保留 |
| causal_connector | 为连接某个已选锚点而保留；不代表自身高异常 |
| no_temporal_witness | 在当前候选窗口找不到规定的时序见证 |
| no_positive_background_lift | 没有正的背景对比证据 |
| background_lift_within_numeric_error | 正差值没有超出迭代误差界 |
| bundle_exceeds_remaining_budget | 终止时完整路径所需新增事件数超过剩余预算 |

保留事件同时记录拥有者锚点、选中步骤和完整见证事件 ID。每步 ledger 记录新增 ID、
新增成本、前后预算、目标增益及单位新增事件收益。

页面可下载 `/api/datasets/optc-0201/decision-audit`，其中包含精简数值输入、选择轨迹、
输入 SHA-256 和证书。第三方可离线重放：

```bash
python webapp/scripts/verify_decision_audit.py downloaded-audit.json
```

该程序检查输入摘要、方向/时间关系、路径束、预算，并重跑对应的选择次序。
证据模式还检查目标增益和松弛上界；扩展上下文模式重放旧锚点边际收益优先级，
不把锚点增益伪装成整条路径总增益。旧策略的删除原因区分“考虑时路径超预算”和“停止前未轮到”。
SHA-256 用于匹配所审核输入，不是独立可信来源认证；需要进一步核对源日志和版本才能确认输入真实性。
小图测试另外用独立穷举目标函数验证选择次序，并枚举可行解验证上下界。

## 7. 为什么现在不报告统计阈值保证

NoDoze 的告警决策阈值依赖标注训练告警；Kairos/Orthrus 也有独立验证数据的使用条件。
Bates 等人的 conformal outlier p-value 保证依赖参考/测试样本的适用分布假设。
本项目当前只有相互依赖的事件、已知攻击 POI 和部分 PDF 指标标签；POI 前历史本身可能已经包含攻击。
不能把这些事件直接当成独立、已知正常的校准集，从而承诺 FPR≤α 或声称得到恶意概率。

以后要验证统计判别，必须单独建立按主机/日期/攻击划分的训练、校准和测试协议，冻结参数，
评估真实标注的误报与漏报、攻击覆盖和人工检查成本，并检查概念漂移与依赖性假设。
当前完成的是可复核调查选边，以及 [开发窗口的预算与敏感性实验](evidence-selection-evaluation.md)。
