# RDP-Guard（稀扩守链）设计说明

## 1. 目标与边界

RDP-Guard 是本项目面向溯源图“依赖爆炸”问题设计的新剪枝方法。它必须同时满足：

1. 从历史数据统计节点类型、边关系和三元行为模式的频次，并将低频事件量化为稀有度；
2. 从告警或关键事件（POI）出发，在时间单调的因果方向上双向传播重要性；
3. 融合稀有度与扩散分数，但不让与 POI 无关的稀有噪声压过常见的攻击桥接事件；
4. 对有序 POI 序列构造并硬保护最小时间因果骨架；
5. 在给定真实事件预算内尽量填满预算，输出可复核的链路完整性证书；
6. Ground Truth 只用于剪枝完成后的离线评估，不能进入 POI 选择、打分或路径修复。

本文中的“保证攻击链保留”是可执行的结构保证：只要用户声明的有序 POI 在候选图中存在且相邻阶段因果可达，输出图一定包含所有 POI 及其相邻阶段的时间因果桥。对于未被 POI 覆盖的未知攻击事件，不做不可证实的绝对保证，而以 CADETS Ground Truth 做独立保留率评估。

## 2. 现有实现失败原因

旧融合方法采用独立加权求和：

`S = w_r R + w_d D + w_p P + w_i I + w_b B`

它有两个结构性问题：

- 一个完全不在 POI 因果走廊中的事件，只要足够稀有，仍会获得较高分数；大量离散稀有噪声因此挤掉攻击链上的高频系统调用。
- `adaptive` 模式按“合并组数量”截断，却用“原始事件数量”计算预算。CADETS 上请求保留 50% 时只保留了 22.8%，导致并非算法有意的过度压缩。

当前有序 POI 的阶段骨架能保留 7/7 相邻阶段，但旧融合在真实 20% 预算下仅保留 3/8 条完整标注路径；相同候选图的时间扩散单独打分可保留 8/8，说明问题在融合和预算分配，不在 POI 覆盖或候选图。

## 3. POI 策略

CADETS E3 采用攻击报告与数据库事件共同验证的八个有序 POI，覆盖：初始 loader 外联、nginx 落地 XIM、XIM 执行、XIM C2、写入 main/test、test 执行和 test C2。选择依据只来自报告中的行为语义以及原始 CDM 事件是否存在；Ground Truth 不参与选择。

每组 POI 必须：

- 按时间排序；
- 显式声明调查时间窗；
- 尽量覆盖攻击阶段转换，而不是重复选择同一阶段的大量事件；
- 以事件而不是高出度节点为种子，避免将繁忙进程的全部邻边误当作告警上下文。

## 4. 频次与稀有度

频次模型只使用 POI 之前的历史数据。对候选边 `e=(u,r,v)` 计算：

- `R_node(e)`：源、目标节点类型频次的稀有度；
- `R_relation(e)`：关系类型 `r` 的稀有度；
- `R_pattern(e)`：三元模式 `(type(u), r, type(v))` 的稀有度。

沿用当前对数归一化，组合为：

`R(e) = 0.2 R_node + 0.3 R_relation + 0.5 R_pattern`

从而显式满足节点类型、边关系和行为模式三个统计层次。

## 5. 时间双向图扩散

扩散以 POI 事件为种子，而非任意节点。后向传播只经过时间不晚于当前锚点的入边，前向传播只经过时间不早于当前锚点的出边；`EVENT_EXECUTE` 等关系使用关系感知的信息流方向。每条边的传播强度包含：

- 阻尼衰减；
- 稀有度/DEPIMPACT 亲和力；
- 繁忙节点的平方根扇出抑制；
- 多个 POI 的最大支持聚合。

得到归一化扩散分数 `D(e) in [0,1]`。该分数表示边处于已知攻击阶段的多跳时间因果走廊中的程度。

## 6. 核心创新：扩散门控稀有度

RDP-Guard 不再让稀有度独立参与加法竞争。对每条边计算：

`S_raw(e) = D(e) * [w_d + w_r R(e) + w_p P(e) + w_i I(e) + w_b B(e)]`

其中 `w_d = 1 - w_r - w_p - w_i - w_b`，最后用全图最大值归一化得到 `S(e)`。

该形式具备三个关键性质：

1. **因果门控**：`D(e)=0 => S(e)=0`，孤立的稀有噪声不能挤掉 POI 走廊；
2. **稀有度有效**：在相同扩散支持下，稀有事件严格优先于常态事件；
3. **常见桥不丢失**：高扩散、低稀有度的系统级桥接事件仍有较高基准分。

旧的加权求和作为 `additive` 兼容模式保留；新实验配置显式启用 `rdp_guard`。

## 7. 路径守卫与完整性证书

设有序 POI 为 `p1,...,pk`。算法对每个相邻对 `(pi,p{i+1})` 在对应时间区间内寻找最小代价时间因果路径，边代价为 `1-S(e)`，并构造：

`C = {all POI edges} union {all adjacent-stage bridge edges}`

`C` 在任何剪枝比例下都是强制保留集合，并扩展到不可拆分的 DEPIMPACT 原子事件组。若 `|C|` 超出预算，算法优先保证证书并显式报告预算溢出，绝不静默删除桥。

结果输出以下证书字段：

- `certificate_poi_edges` / `certificate_retained_poi_edges`；
- `stage_pairs` / `connected_stage_pairs` / `retained_stage_pairs`；
- `path_certificate_valid`；
- `minimum_required_edges`、`budget_feasible` 和 `budget_overflow_edges`。

证书有效当且仅当所有候选图中存在的 POI 都被保留，且所有候选图中可连接的相邻阶段仍然可连接。

## 8. 自适应预算选择

给定事件保留上限 `B=ceil(q|E|)`：

1. 先放入证书集合 `C`；
2. 按原子组的 `max(S)/group_size` 排序；
3. 依次选择仍能放入剩余真实事件预算的组，跳过装不下的大组并继续扫描较小组；
4. 阈值 `tau(q)` 取最后一个非证书保留组的最低边分数；
5. 报告保留的重要性质量 `sum(S_kept)/sum(S_all)`。

因此阈值会随候选图的分数分布、原子组大小、证书成本和存储预算共同变化。它以原始事件数计费，消除组数与事件数错配导致的意外过度压缩。

实验曲线上的推荐点不使用 Ground Truth：选择满足完整性证书且重要性质量达到配置目标的最小保留比例；若没有点达到目标，则选择证书有效且重要性质量最高的点。Ground Truth 指标仅并列展示用于研究评估。

## 9. 验收标准

### 合成测试

- 与 POI 不可达的稀有边分数为零，不能超过扩散可达的常见桥；
- 相同扩散分数下，更稀有的边分数更高；
- 极小预算仍保留全部 POI 和阶段桥，并正确报告预算是否可行；
- 正常可行预算下按原始事件计数，避免旧 `adaptive` 的系统性欠填；
- 旧 `additive` 模式结果保持兼容。

### CADETS E3 实跑

- 使用八阶段 PDF/数据库 POI 和完整 UBC-12 显式窗口；
- 候选图构建必须完整，8/8 POI 命中；
- 20% 或更低真实事件预算下，7/7 阶段对证书有效；
- 目标是在 20% 真实事件预算下达到 8/8 标注完整路径保留，并显著高于旧融合的 3/8；
- 无证书溢出时不超过请求的原始事件预算；
- 运行日志和结果文件均使用日期时间命名。

## 10. 非目标

- 不把 Ground Truth 当作训练标签或在线打分特征；
- 不宣称对未被告警、POI 或候选时间窗覆盖的攻击事件提供形式化保证；
- 不改变 CDM 导入格式或要求预置 SQLite 数据库。
