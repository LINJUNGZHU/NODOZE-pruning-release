# 从可复核节点剪枝走向论文：实验协议与贡献边界

## 研究问题与可检验贡献

给定节点关联的时间锚、背景历史和原始事件预算 B，找出能解释锚上下游关系的事件子集，每个被选择的关联细节都有严格时间见证。目标是保存调查结构，而非以剪枝量代替攻击识别率。

沿用自有频率统计和图扩散：历史条件频率→罕见度→节点个性化传播→事件分数→合法时间路径→预算选择。本轮改变最后两步的候选动作和收益计算：

1. **分辨率可调的事件组**：单个代表、几何递增前缀、全体已遍历可达成员。组由端点和时间窗口自动构造；真实账本 ID 才算候选。传播分数为零的组内成员可以是关联细节，但必须携带见证，不自动标成攻击。
2. **路径共享与组结构一起计价**：收益对所有被路径影响的组计算，而成本是新增原始事件的集合大小。每个动作都保存实际成员和完整见证，阻止“有组引用就视为拥有所有成员”的隐性免费预算。
3. **独立复放的证据合同**：冻结候选和配置，独立评测者回放事件并集、逐步边际收益、严格时间路径和预算。这样的可审计性是工程贡献，需要通过实验再判断其研究价值。

F(S)=Σ_g w_g√|S∩g|+ηΣ_e∈S score(e)，固定 η=1。事件集合上的收益具有递减回报；动作的路径成本存在共享，不是标准加性背包。不能直接宣称 1/2 或 1−1/e 近似保证。最佳单动作与密度贪心的比较只是防止明显密度陷阱的工程控制。

## 开发实验协议

五案使用现有固定映射：Five Dir 1/3、Theia 1/3 和推断映射的 Case 5。最后一案实际上读取 TRACE Case 5 工件映射；尚未证实就是论文 THEIA Case 5，不能作官方 THEIA Case 5 等价实验。B=64/256/1024/4096；候选容量 32768；独立扫描上限 327680；组时间窗口 10 秒。冻结参数后运行质量矩阵和五次独立进程资源重复，不因质量结果重新选择参数。

| 方法 | 作用 | 对比解释 |
|---|---|---|
| history_portfolio | 原频率/历史/传播与路径组合强基线 | 使用完整账本，资源不同，单独标明 |
| v7_group_edge | 上一版组检索与事件收益 | 与 V8 同容量，但检索、动作和单动作控制也变化，不能归因于一个组件 |
| v8_group_edge | V8 完整组候选，线性事件目标 | 与下一行共享完全相同候选池，隔离收益目标 |
| v8_group_concave | 新候选及组凹收益 | 本轮主方法 |
| v8_representative_concave | 只保留代表动作 | 检索策略消融，候选身份不同，不是固定池收益消融 |
| v8_no_frequency_concave | 去频率后的完整流程 | 同时改变分数与候选，是整流程消融 |

所有方法仍是仓库自有实现。不是作者版 SPARSE/SLEUTH/DISTDET/DEPIMPACT 的复现，也不能以论文表格当本地运行结果。

### 指标定义

- known-positive recall = 已保留的本地已知关键事件 / 本地已知关键事件总数。
- incremental recall 排除输入 POI 正例，避免把必选起点当找回能力。
- reference group_any/full：参考工件对应的部分事件组被命中/全部保留的比例。此处参考组仅用于评测，不给算法构组或排序。
- pool_positive_recall：物化候选中的已知正例比例，区分检索损失与最终选择损失。
- 原始事件数量、预算、证书合法率、完整证据并集、合成 LINEAGE 与真实 ID 单独计数。
- FP、FN、Precision、Recall、F1 的官方等价指标均为 NA；未知标签不是负例。论文中的 SPARSE 数字不能用来判定本地每条边真假。
- 选择时间与证书构建时间分开；RSS 是整轮矩阵累计峰值，不写成某个方法的内存。质量阶段和资源重复阶段均最多五个案例进程同时执行，因此计时是此调度条件下的资源记录，不是隔离机器 SLA。

报告 POI 是 oracle 起点，产品人工指定节点也是调查输入，均不能称自动 POI 检测效果。历史窗口使用既有缓存；历史并不保证全为良性，事件元数据的发生时可知性仍为 `metadata_time_safety=unverified`，本轮不宣称严格在线无未来元数据影响。

五案参与过开发，不能叫未见攻击。五次重复测量资源波动，不增加五个案例的统计独立性。

## 投稿前仍需完成的外部验证

1. **主机与时间隔离的未见测试**：仅在开发集选参数；历史严格早于查询窗口。新增攻击不能用来反复调参后继续称测试集。列出候选构造、POI 来源、自动 POI 与人工指定节点两个轨道，自动来源不依赖外部告警。
2. **可独立复现的关键边真值**：两名分析者根据官方攻击叙述和原始事件分开标关键事件及合法路径，裁决分歧；发布可公开的 ID 映射、判定规则、遗漏边界。只有完整审查的窗口才计算通常的 P/R/F1。
3. **基线分层**：作者开源并成功运行的系统、按论文重实现的组件、已有论文表格分栏。PCST/PPR/k-hop/频次排序可在同一候选与原始事件预算上做适配组件对比；适配 PCST 不等于复现 G-Retriever。作者 SPARSE 未能获取逐事件输出时，只做文献比较，不出虚构胜率。
4. **扰动与泛化**：独立控制 POI 错误、历史缺失、频繁攻击行为、组窗口、账本顺序、事件复制；记录候选损失和时间合法性。敏感性参数范围先登记，开发与验证分开。
5. **人工调查效用**：全图、纯频次、节点剪枝随机交叉；同样问题、不同案件、分析者盲于方法；记录任务正确率、用时、事件查看数。不能由 98% 减量推导节省 98% 调查时间。
6. **扩大规模与资源**：单方法隔离进程、至少五次、冷启动和纯算法分开，发布硬件/线程/版本；明确完整加载账本的内存成本。以未见案件配对差异和区间报告，不对五案重复点做伪显著性检验。

若 V8 输给强基线，保留失败案例，分析候选进入率与选择损失；产品使用已验收版本，V8 保持研究模式。不能以新的目标值更大推导关键事件召回更高。

## 跨领域借鉴

- [G-Retriever, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/efaf1c9726648c8ba363a5c927440529-Abstract.html)：文本图检索中以 PCST 在上下文预算下取关联子图。借鉴预算下结构检索的建模，不复现其语言模型和 QA 系统。
- [Iyer & Bilmes, AISTATS 2019](https://proceedings.mlr.press/v89/iyer19b.html)：缓存可维护统计来加速子模优化。借鉴事件到动作的反向索引和组计数更新，仍独立核验字面目标。
- [Yaroslavtsev et al., AISTATS 2020](https://proceedings.mlr.press/v108/yaroslavtsev20a.html)：标准线性背包约束下的 Greedy+Max。本实现只采用贪心之外检查单动作的启发，不是论文算法，路径共享成本不满足其假设。

## 复现

Python 环境须包含 numpy、scipy 与仓库已有依赖。原始日志/历史缓存不上传 GitHub。质量运行器在读标签之前完成输出：

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python scripts/run_group_completion_v8.py --case 0 --data-root /path/to/data --output-dir /path/to/quality
# 同样执行 case 1..4；五次资源重复用不同目录并加 --profile-only
PYTHONPATH=. python scripts/evaluate_group_completion_v8.py --input /path/to/quality --profiles /path/to/profiles --output docs/group-completion-v8/results.json
```

`profiles/repeat0..repeat4/case0..case4`。运行器拒绝覆盖已有 manifest。决策冻结哈希、来源哈希和实际 Git 提交均在 manifest 中；评测发现代码/账本/候选/决策改变时拒绝出结果。
