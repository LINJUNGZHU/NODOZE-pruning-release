# V8：分辨率可调的完整事件组与精确并集边际收益

用户授权：自主实现、实验、发布 GitHub，不要求确认。
目标：保留频率统计 + 图扩散，修复 V7 组引用不等于事件物化，以及零分组内细节被跳过的问题。新轮次独立冻结，保留所有旧结果和产品默认。

## 方法
- 按现有频率与扩散排序事件组。组的优先级来源于无标签传播分，组内零分事件只可作为有合法时间证书的关联细节；不能据此判恶意。
- 一等动作：代表事件、几何递增前缀（继续展开）、完整组。每个动作携带所有成员的合法见证，事件并集决定成本；重复连接边只计一次。
- 候选容量为 32768 个真实账本 ID，扫描最多 327680 个独立事件；先用四分之一容量探索代表，再分配逐步展开。拒绝超容量动作，不假称未物化成员已入池。
- 精确目标：F(S)=Σ_g w_g sqrt(|S∩g|) + ηΣ_e∈S score(e)，η=1。逐动作计算所有受影响组与共享路径的真实边际收益，不用只计动作所属组的近似。收益不依赖标签；不继承标准加性 knapsack 的近似比。
- 比较密度贪心与最佳可行单动作，择目标值更大者；不是 label oracle。
